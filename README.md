**How to install this trainwreck - presented by the Mappa Mundi team**
1) Download the Mappa-Mundi-sine-Tempore.zip file.
2) Unzip the folder.
3) Extract the folder "Mappa-Mundi-sine-Tempore-main" to anywhere on your PC.
4) Head over to https://www.python.org/downloads/ and click "Download python install manager."
5) Run "python-manager-26.XX.msix" installer. It will request system admin so hit yes.
6) Hit Y on everything as it opens your command prompt for downloading other systems that help Python to run properly.
7) Run the "start_server.bat" file.
8) The python script will open a Powershell prompt briefly, then a command prompt which you can safely close.
9) It should open your browser, with the address of "localhost:8000" as well as a new tab named "Map Sandbox."
10) Play and enjoy. This application now runs offline as well!
